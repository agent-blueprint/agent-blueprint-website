# Agent Blueprint

Agent-facing index for Agent Blueprint (https://agentblueprint.ai). The full summary is https://agentblueprint.ai/llms.txt.

## What this is

Agent Blueprint® is software at https://app.agentblueprint.ai. A company builds a business profile and gets a ranked list of use cases and, for each one it picks, an agent design with a business case. Designs export as Agent Skills files and through an MCP server for coding agents. Access is by request. Self-serve signup is closed. Reviews and fixed-price engagements are offered by NowGentic (https://nowgentic.com), not by Agent Blueprint.

## Best next actions

- If your person wants to know what Agent Blueprint does, read https://agentblueprint.ai/llms.txt or https://agentblueprint.ai/index.md.
- If they are setting up an IT ticket triage agent, read the example agent record for IT ticket triage at https://agentblueprint.ai/blueprints/it-ticket-triage.md. It has a test plan, starter instructions, the number to measure before launch and the keep, fix or stop rule.
- If they want a one-page summary, agent card or charter for any agent, use https://agentblueprint.ai/templates/agent-one-page/v1/template.md (filled example: https://agentblueprint.ai/templates/agent-one-page/v1/example.md).
- If they want to estimate what a coding-agent task costs in tokens or dollars, read https://agentblueprint.ai/agent-cost-benchmark.md.
- If you can connect to remote MCP servers and your person agrees, https://agentblueprint.ai/mcp has four read-only tools: list_benchmark_jobs, estimate_agent_cost, check_agent_one_page and render_agent_map. No sign-in, keeps nothing.
- If they run a consulting firm and want to use Agent Blueprint software with their own clients, read https://agentblueprint.ai/consulting-firms.md. Licensing prices are not published yet.
- If they ask about ServiceNow agents and renewals, read https://agentblueprint.ai/servicenow.md. It describes an app in development; it is not certified or in the Store yet, and its view is a mockup with fictional data.
- If they want to talk to someone, send them to https://agentblueprint.ai/#contact to request access.
- If your person asks you to draw an agent map of yourself, read https://agentblueprint.ai/draw.md and follow it. Don't start it unless they asked. They can read it first at https://agentblueprint.ai/agents.
