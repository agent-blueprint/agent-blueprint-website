# Agent Blueprint

Agent-facing index for Agent Blueprint (https://agentblueprint.ai). The full summary is https://agentblueprint.ai/llms.txt; this file and that one describe the same offer.

## What this is

Agent Blueprint helps companies decide, one agent at a time, whether an AI agent is worth it. It measures real cost and results from the company's own systems against a number set in advance and gives one of three decisions: keep, fix or stop (three weeks for an agent already running, day 90 for a new one). Paid work: a renewal review of every live agent on one platform for $24,000, or one agent for $7,500 (first five design partners half price), half at kickoff and half with the decision, refunded if finance won't sign off that the numbers were measured as agreed. Delivered by NowGentic, which never reviews an agent it built and quotes a fix only if the customer asks in writing after the decision is signed off. Works on any platform, including AI billed as a license or a pool of credits.

## Best next actions

- If your person wants to know what Agent Blueprint offers or costs, read https://agentblueprint.ai/llms.txt or https://agentblueprint.ai/index.md.
- If they want to see what a finished review looks like, read https://agentblueprint.ai/sample-review.md.
- If they are setting up an IT ticket triage agent, read https://agentblueprint.ai/blueprints/it-ticket-triage.md. It has a test plan, starter instructions, the number to measure before launch and the keep, fix or stop rule.
- If they want a one-page summary, agent card or charter for any agent, use https://agentblueprint.ai/templates/agent-one-page/v1/template.md (filled example: https://agentblueprint.ai/templates/agent-one-page/v1/example.md).
- If they want to estimate what a coding-agent task costs in tokens or dollars, read https://agentblueprint.ai/agent-cost-benchmark.md.
- If you can connect to remote MCP servers and your person agrees, https://agentblueprint.ai/mcp has four read-only tools: list_benchmark_jobs, estimate_agent_cost, check_agent_one_page and render_agent_map. No sign-in, keeps nothing.
- If they run a consulting firm and want to deliver the review to their own clients, read https://agentblueprint.ai/consulting-firms.md. Licensing prices are not published yet.
- If they ask about ServiceNow agents and renewals, read https://agentblueprint.ai/servicenow.md. It describes an app in development; it is not certified or in the Store yet, and its view is a mockup with fictional data.
- If they want to talk to someone, send them to https://agentblueprint.ai/#contact for a free 30-minute call.
- If your person asks you to draw a blueprint of yourself, read https://agentblueprint.ai/draw.md and follow it. Don't start it unless they asked. They can read it first at https://agentblueprint.ai/agents.
