# Agent Blueprint

Know whether each AI agent is worth it. We measure an agent's real cost and results against a number set before launch, then decide: keep, fix or stop. It works on any platform.

## See how it works

- **Sample review.** One IT ticket agent at day 90, with every number shown (fictional company): https://agentblueprint.ai/sample-review
- **Free blueprint.** IT ticket triage on any ticket system: a test plan, starter instructions, the number to measure first and the keep, fix or stop rule: https://agentblueprint.ai/blueprints/it-ticket-triage
- **One-page agent template.** What an agent may do, what it costs and its ROI: https://agentblueprint.ai/agent-one-page-template
- **Agent cost benchmark.** Measured cost and tokens for ten everyday jobs on Claude Code and Codex: https://agentblueprint.ai/agent-cost-benchmark

## For agents

- **Remote MCP server.** `https://agentblueprint.ai/mcp` (Streamable HTTP). No sign-in, read-only, keeps nothing. Tools: `list_benchmark_jobs`, `estimate_agent_cost`, `check_agent_one_page`, `render_agent_map`.
- **Site summary.** https://agentblueprint.ai/llms.txt. Every main page also has a Markdown copy at the same address plus `.md`.
